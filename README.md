
# Password Strength Checker

A simple and fun C program to check how strong your password is.  
It evaluates based on:
- ✅ Length (10+ characters)
- ✅ Special characters
- ✅ Numbers
- ✅ Uppercase letters

##  Features
- Clear, user-friendly messages with emojis
- Score system out of 8
- Instant feedback on password strength
